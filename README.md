# Thesis Repository

Code and supporting files for XRF and ER-FTIR analyses.

- `XRF/XRF_simulation/`: XRF spectrum simulation code and notebooks.
- `XRF/XRF_simulation/example_files/`: example simulation inputs.
- `XRF/XRF_NN_model/`: XRF neural-network notebooks and code.
- `XRF/XRF_NN_model/example_files/`: example neural-network inputs.
- `ER-FTIR/`: reserved for future ER-FTIR work.
